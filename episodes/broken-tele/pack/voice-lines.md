# Broken Tele: voice lines

**How to record.** One file per actor, all their lines in order, each line read once (or twice if you want a
choice), with a one or two second pause between lines. Don't read the line numbers or the notes. Phone recordings
are fine: a quiet room, the phone about a hand's width from your mouth. Name the files:

- `02-family-mum.m4a` (Mum)
- `03-family-dad.m4a` (Dad; the shop assistant's one line too, if Dad's actor does it in another voice)
- `04-shop-assistant.m4a` (only if someone else reads it)

The boy's lines are already recorded.
