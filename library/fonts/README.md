# Fonts

For on-screen text (captions, title cards, props). All under the SIL Open Font License 1.1, so they can be
bundled and used in the videos.

| File | Font | Use |
|---|---|---|
| `BebasNeue-Regular.ttf` | Bebas Neue (Dharma Type) | titles, names, signs |
| `Inter.ttf` | Inter (variable) | caption second lines, small print |
| `Montserrat.ttf` | Montserrat (variable) | spare |
